Определи организационную структуру по разделу документа «{{label}}» (положение о подразделении).

Нужны структурные единицы:
- блок/служба верхнего уровня (kind = "block"), если документ его называет;
- департаменты, управления, отделы (kind = "department");
- направления, сектора или группы без собственного департамента, в том числе когда документ называет только руководителя направления (kind = "direction"; name — название направления);
- руководящие должности (kind = "position") — только Главный аудитор / руководитель блока. Директоров департаментов как отдельные единицы не возвращай: они входят в свой департамент.

Для каждой единицы верни: name (полное название как в документе), abbr (аббревиатура из документа или null), kind, parent (abbr или name единицы, которой она подчинена, или null), source_clause (пункт, где единица названа; только из списка ниже).
